# V1

## colecciones(): vehiculos se deriva de datos, no del rol
ParametrosController::colecciones() NO asume que el usuario sea conductor. persona->conductor puede ser null (jefe de área) y una persona puede tener ambos roles. El array `vehiculos` unifica con unique('id'): conductor->asignacionesActivas + los vehiculosActivos de persona->encargadoAreas() (áreas que administra como jefe de área). `areas` (para actividades sugeridas) = conductor->areas() + encargadoAreas()->pluck('id'). Si no es ninguno, vehiculos llega vacío (ya no hay 500). Cubierto por ParametrosControllerTest.
